# Live UI Update

Live UI Update is part of the **MILAN ecosystem**.

It focuses on the production web experience, interface evolution, and fast iteration of the MILAN application.

## Role in the MILAN ecosystem

- **MILAN App** — the main decentralized social application
- **DWN** — decentralized data and storage foundation
- **Natively DWN Wallet** — wallet and user-side DWN interaction layer
- **Live UI Update** — production-facing UI iteration and experience layer

## Product Context

MILAN is being built around user-owned identity, decentralized data, and a Web5-oriented architecture.

This repository supports the interface layer that turns those capabilities into a usable product experience.
